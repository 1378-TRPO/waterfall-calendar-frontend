# waterfall-calendar-frontend

Фронтенд учебного веб-календаря «Календарик» для маленькой компании. Методология Waterfall.

- SRS: [tec-doc-waterfall](https://github.com/1378-TRPO/tec-doc-waterfall) (docs/01-srs.md)
- Бэкенд: [waterfall-calendar-backend](https://github.com/1378-TRPO/waterfall-calendar-backend)

## Стек

React 19, TypeScript, Vite 8, React Router 7, TanStack Query 5, Axios, Tabler Icons.

## Запуск

Нужен Node 22+ и работающий бэкенд на `localhost:5067` (см. README бэкенда).

```
npm install
npm run dev
```

Приложение открывается на `http://localhost:5173`, запросы к `/api` проксируются на бэкенд.

## Скрипты

| Команда             | Что делает              |
| ------------------- | ----------------------- |
| `npm run dev`       | дев-сервер Vite         |
| `npm run build`     | проверка типов и сборка |
| `npm run lint`      | ESLint                  |
| `npm run typecheck` | только проверка типов   |
| `npm run format`    | Prettier по всем файлам |

## Функциональность

- Регистрация и вход (JWT, 8 часов), выход.
- Календарь в трех видах: месяц, неделя, день; переходы вперед/назад и «Сегодня».
- Создание и редактирование записей: встречи, задачи, напоминания; валидация времени.
- Карточка события: состав участников, RSVP (приду/не смогу), отмена встречи, пинг участника.
- Уведомления с бейджем непрочитанных и страницей уведомлений.
- Панель «Ближайшие» слева от сетки: ближайшие встречи и быстрые кнопки RSVP.
- Тема оформления: светлая, темная или системная.

## Известные ограничения

- Мобильная верстка, часовые пояса и drag-and-drop вне scope MVP (см. SRS, раздел 5).
- Ссылка на видеоконференцию в повторах встреч генерируется как демо (`https://meet.local/...`).
- Уведомления обновляются опросом раз в 30 секунд (без WebSocket).
